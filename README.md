# GutterCalc

Gutter size calculator: downspouts from roof area, 5 vs 6 inch gutter sizing by rainfall zone, slope, hangers and cleaning schedule.

## Features
- K-style vs half-round gutter compare
- Rainfall-zone sizing
- Cleaning schedule planner
